Since can be a bit confusing because it has two different uses. 

First, when you tell a story, you often start with the beginning. You might say, like, a long time ago. This means that something happens before the rest of the story. This is because time goes in one direction only. When you start a story, you are at the start of your story, and you are since it begins.

Think of a line of food. You start at the beginning with the first bite and go all the way to the end. So, when you say you are since the beginning, you are talking about a time that has already started. It is not something that is happening right now.

The second use of since is a word that helps you talk about how you feel. When you are very angry, you might shout. You are since you have been angry for a long time. This means you started feeling this way a while ago.

You can also use since to talk about what is happening now. If you are waiting for a friend to come, you might say, since  you left the house, you have been waiting for a long time. This means you started waiting before you left.

Sometimes, since is used with other words. If you have been doing something, you might say, since you started, you have been doing it for a long time. This is like saying, since you started working, you have been working for many years.

So, since is a word that helps you understand time and how you feel. It can tell you when something started, how long it has been going on, or how you are feeling right now.
