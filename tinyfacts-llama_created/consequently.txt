To do something because you are doing it is called doing it because you are doing it. This is about the way we use words. 

If you say, a book is a thing you read, it is a fact. You are not doing it because you are reading, you are just saying it. But if you say, the sun will come out tomorrow, you are doing it because you are waiting. You are not just saying it, you are doing it.

Because is a word that helps us. We use it to show how things are. If we say, because the book is out of the way, we are showing that the book is first. We are not saying the book is out of the way because we are looking at it. We are saying it because the book is there.

Sometimes, to say something is because you are doing it is a little confusing. But it is actually about the way we use the word. It is about the act of doing something.
