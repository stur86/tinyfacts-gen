An idea is a way to do something. An idea is a way to think about a problem so you can find the right answer.

A computer can follow these steps:

   Shows you a picture for a few seconds.
   Shows you a picture for a few seconds.
   Does the same thing for many pictures.
   When you want to see a picture, the computer shows you the one it has found.

Alone, this is not very good. It uses many steps. It uses a lot of memory. It uses a lot of time. If you want to see a picture quickly, you can use an idea.

An idea is made up of many things. The first part is the part that says how to go. The next part is the part that tells the computer what to do. The computer follows these two parts.

There are many different ways to make an idea. Some ideas use a few steps. Some ideas use many steps. Some ideas use a lot of numbers. Some ideas use a lot of words.

If you know how to follow an idea, you can find the right answer. You can use the idea to do many things. You can use it to find the right word to say in a conversation. You can use it to find a way to fix a car problem. You can use it to see a picture.

Most computers use this kind of idea. They follow these steps. They use these ideas to do many things. They are very good at it.
