To use a thing as a way to start a fight is to use it to make someone angry. When you say this, you are not really talking about the thing. You are talking about the person you are talking to. You are trying to make them angry so they can do something.

Think of a gun. If you hold the gun and then you pull the thing, the gun will go off. This is like the thing. It is the thing that will make the person angry. You are using the thing to make the person angry.

Sometimes, we use words like this in writing. If you write something that makes someone angry, you did it. It is not the word you used that made them angry. The thing you used is the thing that made them angry.

This is why we need to use these kinds of words carefully. We do not want to start a fight because we are angry. We want to use words that will make people think.
