To use something means you are using it. You are using the thing that is not your own. You are taking it from someone else.

Think of a door. The door is the thing you use. You go inside it. You walk on the floor. You use the door to go where you want to go. You are using the door.

You can also use something for your own fun. You might play with a ball. You throw the ball and run with it. You are using the ball.

If you do not use something, it is dead. A car is dead when it does not move anymore. A book is dead when it is broken. You must use the things that are living to stay safe.

Sometimes, when you are using something, you might feel a bit confused. Maybe you want to use it but you do not know how. You might feel like you are in a big problem. But then, you do it. You finish what you started. You are using the thing.

You can use things that make you feel happy, like music or a funny movie. You might watch a movie and laugh. You are using the movie to make you feel better. You are using the movie for fun.

You can also use things that help you when you are sick. You might use a water bottle. You drink from it. You are using the bottle to stay well.
