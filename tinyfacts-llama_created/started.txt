To start something is to begin it. It means you begin a new time or a new thing. You start a story, a game, a day, or a work. When you start a new thing, you do it first.

Imagine you want to learn a new word. You sit down and think about it. You do not know it yet. You look at the word many times. Then you remember it. You start to know it. You have learned it.

You can start a fight. You start by saying, I am the one who does it. You start by being strong. You start by doing something.

You can also start a work. You start a job. You start to do the work. You work hard. You complete the work.

In your life, you start many times. You start a new school year. You start a new job. You start a new relationship. Each start is a new beginning.

The word started is used when something begins. It is used in many different ways.
