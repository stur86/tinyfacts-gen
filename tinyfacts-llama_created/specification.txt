A way to tell what is needed is a very important thing. You can not build a car without knowing how the car should look, how the car should move, and how the car should work. You can not build a house without knowing how the house should look, how it should be made, and how it should be safe.

When you write a set of words that say how something should look, how something should move, or how something should work, you are making a very clear way for other people to know what you want. This way, other people can build something that is the same as what you said they should make.

Think of it like a set of numbers. Each number tells you a piece of the picture. If you have a set of numbers, you can build a picture that looks the same. If you give someone a set of numbers, they can build a picture that looks like yourself.
