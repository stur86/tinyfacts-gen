A number is a thing that helps us tell how many things there are. When you say, I have ten of them, you are telling everyone how many ten things you have.

A number has only one number. You can not have two or more. You can only have one ten, one twenty, one hundred, and so on. We write these numbers so we can write things down.

There are many kinds of numbers. One is a number that is one. Two is a number that is two. Three is a number that is three. The number ten is one ten. The number twenty is two ten. And so on.

When we use numbers, we can tell how many of something there are. If you have one bag of sweet things, you have one bag. If you have two bags, you have two bags. If you have three bags, you have three bags. This helps us know how to do things with things.

To make a number, you start with one. You add a few more numbers together. If you add one, two, and three, you get four. If you add two, three, and three, you get five. If you add three, four, and three, you get six. This is how you make numbers.

Numbers are very important. You need them to tell where things are. You use numbers to write things you want to remember. You use numbers to tell how much money you have. You use numbers to tell how many minutes you have before you have to go to bed.
