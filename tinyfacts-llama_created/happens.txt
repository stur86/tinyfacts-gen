When something happens, it is an eventually true thing that has been done or will be done. It is an eventually real thing because it is not a thing you can see or touch. You can not see it with your eyes. You can not touch it. It is only a thing that is going on.

Think about the sun. The sun is a thing that happens in the sky every day. It is a real thing, but you do not see it. You do not touch it. You only see it when it is up in the sky. The same is true for many other things. The air moves, the water moves, people move, the ground moves. These are all things that happen.

Things that happen are the same as things that are. A thing is a thing that can be seen or touched. A thing that happens is a thing that is real and happens. This is why the word happens is often used instead of things that happen.
