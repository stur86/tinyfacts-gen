Should is a word that means you think something is right or wrong. It is like a line that you walk. If you walk on this line, you are doing the right thing. If you cross this line, you are doing the wrong thing.

Imagine you want to go to the park. If you should go there, it means you should go. You do not need to tell anyone. You just know. This word is important in many ways.

Sometimes, you might feel sad or angry. You might want to do something that makes you feel better. You might want to cry. You should do this. This is because you are feeling how you should feel. If you did not feel this way, you would not be able to help yourself.

You should also be kind to others. If you see a friend who is happy, you should say hello. You should listen to what they say. You should help them if they need it. This is a way to show you care.
