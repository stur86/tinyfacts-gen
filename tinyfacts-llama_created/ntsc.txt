To set a high number means to give a number very high.

When you watch a movie, the picture is very clear. But if the picture is set too high, it looks like stars in the sky. This can make the picture look very strange.

If you set a number too high, you are breaking the computer. The computer does not know what to do with the high number. It will get very confused and might stop working.

In the world of computers, there is a set of numbers that tell the computer what it should do. This is the set of numbers the computer follows. When you set a number too high, you are breaking this set and the computer is not following it. This is why you need to make sure the number is not too high.

You can also set a high number for a game. If the number is too high, a player might not be able to get the right number to winding the game. The game might go on for a long time because the numbers are not matching.

In short, setting a high number means giving a number that is too big. It can make things look strange or cause a computer to break.
