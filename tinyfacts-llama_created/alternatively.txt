To do something different is to act in a way that is not the same as the first time. It is when you change the way you act so that you are doing the same thing, but you are not the same person.

You can think about it this way. Imagine you are walking through a room. You start by walking straight. Then you turn around and walk back in the same direction. You are doing the same thing, but you are not the same person. You have changed. You did not stay the same.

Sometimes you do something different. You eat a different food. You drink a different drink. You wear different clothes. You do the same thing, but you are not the same person. You have changed.

We also do this in our lives. We change jobs. We move to a new town. We start a new school. These changes are different from the first change. You are not doing the same thing, but you are still doing the same thing.

Sometimes we change for one day. We get a new job, or a new phone. We go to a new school. We meet new people. We learn new things. These changes are different from the long changes, but they are still changes.
