Each is a word that tells you how many things are in a group. It shows each one of them.

Imagine you have many friends. You might say,  Each person is different. That means each person has their own face, clothes, and story. You know each of them as an own person.

We use this word when we talk about many things. If you have many books, you might say, There are each books. Each book is a piece of paper with words on it. You are looking at each book one by one.

In school, we use this word when we write about a whole group. If you write, There are many books, you mean there are many books. Each book has a story and words.

You can also say each person is important. If you have many friends, you need to know each one so you can say thank you to them. You need to remember each name, face, and story.

This word is also used when you are looking at things. If you look at a big house, you are looking at each room. Each room is a part of the house. You see how each room is built with walls, windows, and doors.

So, each is a word that tells you how many things are in a group, how many people are in a group, or how many parts are in a whole.
