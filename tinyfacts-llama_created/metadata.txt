To put something in a listens place is to give it a name. This name is for people who want to use it. When you put a picture in a book you read, you put the name of the book first. If you want to find the picture later, the name is the first word of the listens place.

A person can also put a name in a box. If you use this box to keep a note, you put the name and the date in it. When you want to look at the note later, you can open the box. This way you can see what the person wrote down without having to read the whole book.

In the world of computers, people use this word. They put the name of a picture in a box. This box tells the computer what the picture is about. If you want to see the picture, you open the box. The computer looks at the name and shows you the picture. It is like putting a name in a box so you can find what you want later.

Sometimes we put more than one name in a box. If you have a phone number and a name, you can use the name so you can find the person. The phone number is like the box, and the name is the name you use to find the person.
