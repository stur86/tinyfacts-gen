A name space is a place where things happen. It is like a box in a computer. This box is not in your world. It is not in your home, or your school, or your family. It is only in the computer.

Imagine you have many boxes in your home. Each box has a number on it. You can find your box with the number  five. You use the number to find the box where your food is. But if you move to another town, your number does not change. You still know where to find your box in the new town. This is like a name space.

When you build a computer, you put many of these name spaces together. You put the number of the computer, the number of your word book, the number of your pictures, and the number of your music. All these numbers are in the same name space. This is how the computer knows which box to use for each thing.

Sometimes, people use this word in other ways. They say a book is in a name space. This means the book is in a place where you can find it. They say a word is in a name space. This means the word is not in your word book. It is in a different place where the word is kept.

In a big city, there are many name spaces. Each name space has many more name spaces. It is like a big tree with many more trees. Each tree has many more name spaces. This makes it very hard to find the right name space.
