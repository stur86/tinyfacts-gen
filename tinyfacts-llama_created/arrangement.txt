To put things in a line or a way that shows who is near to who.

Imagine you have a big box of things to put away. You want to put the things that are very small in a box that is very small. Then you put the small things in a line with the big things so they are all in the same line. This is an order. This is an order because it shows what is first and what is next.

You can also put things in a way so they are near each other. If you have books to put in a book stand, you put the books that are very far from each other next to each other. This makes it easy to find a book. You put things near each other so they do not get lost.

Sometimes, you have many things that you do not remember. You put them in a box so you can find them later. This is an order. It is like putting a key in a lock so the door opens. The key tells the lock what to do.
