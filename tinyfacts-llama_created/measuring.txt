To be a number means you are a part of a set. One number is a one, two is a two, three is a three, and so on. You can also be a number of something. If you have two books, then you have two numbers.

A person can also be a number. A person can have many numbers. You might have many friends. You can also have many jobs. Each job has a number, like a school number.

To be a number also means you are a place. When you write something on a paper, you write it with numbers. You can write a number of letters. If you have five letters, you write five numbers. You can also write a number of words. If you write a story with five words, you write five numbers.

Sometimes, to be a number is to be very, very small. If you look at a tiny bit of hair, it is a number. You can counters these tiny bits to get a very small number.

In the world, numbers help us. We use them to build things. We use them to buy things. We use them to tell time. We use them to play games. Without numbers, we could not do anything.
