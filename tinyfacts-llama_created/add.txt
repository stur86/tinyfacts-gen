When you add something to something else, you are making it bigger. You are making it more.

Imagine you have a book with  five hundred words. If you add a picture to it, the book now has more than five hundred words. The picture is part of the book now. You have a new thing that is a part of the old thing.

You can also add things that are not words. You can add a number, a color, a sound, or a smell. If you add these things, the new thing is bigger than the old thing. You are making it more interesting.

If you add two small things, they become one small thing. If you add two big things, they become one big thing. This is how we get more when we add things together.

You can add things to each other. If you add a red ball to a blue ball, you get a new ball that is red and blue. You have two balls now with different colors.
