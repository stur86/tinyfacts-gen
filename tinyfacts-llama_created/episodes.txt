To have an eventually is to have something that is eventually happening. You have a plan. You want to do something. Then things start to happen. You are doing it. The plan is not the end. It is the start. You are not done with the eventually. It is going on. It will go on for a long time.

Think about a story. There is a beginning. There is a middle. There is an end. Each part is important. If you do not know what is going to happen next, you do not know if the story is finished. An eventually is like a story that keeps going.
